# Web v3.7验收

1. 页首显示WEB3.7，中英文均可切换，继续使用NOGUARD固件。
2. 英文LLM返回500–3000字符的有效说明时，候选可通过文本校验并进入既有PREP/APPLY/评价流程。
3. 无效JSON、说明超过3000字符、接口失败或输出截断时，训练页保留失败阶段、原因及候选发送状态；停止/解锁确认不会覆盖原因。导出JSON含lastFailure。
4. 状态页分别显示Angle(°)与Gyro(raw)曲线，双轴各自带刻度、量程与同一30秒时间范围；较大陀螺原始值仍应完整落在图内。
5. 原有人工PID、自动接受/回滚、遥控、3秒/1秒窗口和5Hz保持原逻辑。本地模拟测试不等于实车Bluefy验证。
