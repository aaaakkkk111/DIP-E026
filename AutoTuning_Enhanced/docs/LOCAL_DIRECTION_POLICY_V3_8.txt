

LOCAL COMPARISON FIRST — DIRECTION BEFORE MAGNITUDE
Before choosing gains, read local_direction_summary and the current metrics, then use recent_history for detail. The summary describes only confirmed applied trials in this automatic run, with the same source and a connected resulting-PID path. Accepted and rolled-back trials both contain useful measured responses; an accepted trial is not necessarily an improvement, and a rollback alone is not proof that AD caused a problem. Comparisons show observed window differences, not statistical significance. Check changed_parameters: if multiple gains changed, AD's isolated effect is unknown. Current external conditions may have changed even within a run.
First state the leading direction/hypothesis; then decide how large the change should be and whether AP, VP/VI or steering gains should move together. Apply these conditional priorities:
1. If osc remains problematic and a recent AD increase raised osc, prefer reducing AD. Do not repeat an increase justified only by "high-frequency vibration needs more damping".
2. If reducing AD lowered both osc and lean, continue that evidence-supported direction or hold to observe. This is not a rule to decrease AD forever.
3. If a further AD decrease worsened osc or lean, stop blindly decreasing AD and reassess the tradeoff. Do not automatically reverse direction or replay a failed PID vector without new evidence.
4. If osc is already low relative to current measured context but low-frequency sway/lean remains, focus the hypothesis on AP and the velocity loop, rather than automatically changing AD. lean is not fore-aft travel distance.
5. When the current experiment's stated stability objective has been met, return hold with current_pid unchanged, pause parameter exploration and reobserve using the existing loop. No numeric stability target is currently configured: do not invent one, impose universal osc/lean thresholds, or equate an ACCEPT with a stability goal.
Without recent local trials, use current telemetry and the conditional empirical priors. In the user's unloaded AP150/AD120/VP62/VI31/TP17/TD20 high-osc test with angles still comparatively bounded, lowering AD is the leading initial hypothesis, consistent with the AD100 counterexample. This is a scenario-specific direction, not a fixed target or a rule for a low-AD large-angle failure. AP coupling and VP/VI changes depend on current lean and measured response. Do not infer that all high osc means AD is too low.
These are priorities, not permanent prohibitions. A reversal must cite NEW relevant measured evidence in expected_effect (or reason for review): reference a local trial id/time and before/after values, or a new current-baseline pattern/context change that contradicts the old hypothesis. If no such new evidence exists, do not reverse solely on a generic damping statement. If evidence is mixed or confounded, say so and use honest confidence.
All six gains remain available for large, coordinated changes within existing absolute ranges. No new percentage cap, single-gain rule, candidate schema field, acceptance criterion or firmware command is introduced. Preserve the existing output schema and measurable-experiment distinction. This policy guides the model's explanation and proposal; it does not create a deterministic AD controller.
