# Web v3.9：允许首轮大步纠偏

只新增首轮提示词和请求中的 tuning_round.number / tuning_round.first_round。每次主动开始自动运行时首轮为 true，第二轮及以后为 false；停止后主动重新开始会开启新一轮会话。

当前基线存在持续异常、实测形态和条件性经验支持方向时，首轮允许直接提出大幅纠偏，不要求先试极小幅度、不以缺少本轮 A/B 历史为由默认小步试探。先判断方向，再根据异常程度、条件匹配程度选择幅度。六参数可大幅协同改变，没有新增百分比限幅、最低步长或置信度门槛。

对于空载 AP150/AD120/VP62/VI31/TP17/TD20、高 osc 且倾角相对受控的场景，首轮可以显著降低 AD，并结合 lean/角度决定 AP、VP/VI 是否联动；没有硬编码到 AD48 或其他标准参数。低 AD 大角度失败不适用同一方向。稳定或数据不足时仍可 hold，首轮大步是许可而非强制。

后续仍依实际试验结果、局部方向证据决定继续、保持或修正。可选独立审核同步收到该许可，不能仅因首轮幅度较大或缺少本轮对照就拒绝。

v3.8 局部方向规则原文保留，固件与 HEX、参数绝对范围、评分、接受/回滚、3 秒采集 / 1 秒评价、轮间等待、BLE 协议及界面布局均未改变。无需重新烧录。

完整提示词：LLM_SYSTEM_tuning.txt / LLM_SYSTEM_review.txt。本次附加段：FIRST_ROUND_POLICY_V3_9.txt。

验证：91 项自动测试通过；中英文 430×932 浏览器测试通过，模拟设备的首轮大幅协同候选已进入 TRIAL 并读回确认，停止后基线恢复。浏览器使用拦截 API 响应，没有调用付费模型或验证实车效果。测试中的数值仅检验流程，不是实车参数推荐。
