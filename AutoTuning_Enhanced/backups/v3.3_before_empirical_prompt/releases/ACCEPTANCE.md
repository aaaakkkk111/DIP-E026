1. 烧录releases/stm32_Balance_Car_RA1_9_AUTO6_TXFIX_VP100.hex，Bluefy打开?v=VP100-3.3；状态版本应为RA1.9-AUTO6-TXFIX-VP100。
2. 3.TEST模式启动平衡。确认快遥测仍约5Hz，GET/PID正常。初始96/48/62/31/17/20没有改变。
3. 人工VP76/80/84应返回MSET ACK并读回一致，其他五参数保持原值；>100应拒绝。只扩大VP，不扩大其他参数范围。
4. 新网页连接旧固件仍限制VP72；必须收到VP100标记才开放100，LLM动态范围同样跟随。
5. 自动采集3秒、评价1秒及原ACCEPT/ROLLBACK继续运行。新范围不表示已证明更好的PID；这次机器验证未连接真实小车或真实付费LLM。
6. 导出原始JSON/日志，附同样地面、负重、电压及前后活动范围。72到100逐步试验，不要求立即测试100。
