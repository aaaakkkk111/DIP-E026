# Web v3.1验收

已有RA1.9固件无需重新烧录。请用Bluefy刷新?v=AUTO6-3.1并确认版本。

1. 调参页只显示启动/停止主要按钮，无人工采集、JSON编辑、PREP/APPLY/ACCEPT入口；PID页独立人工调参保留。
2. 已启动平衡并完成通信确认后，设置LLM接口，点击启动，自动锁定人工PID并依次显示采集/LLM/应用/评价/下一轮。
3. 采集和观察进度来自实际时间/样本，不为LLM请求伪造百分比。核对当前/候选六参数、模型理由、代价图和每轮结果。
4. 检查请求允许大幅六参数协同变化；实际ACCEPT必须收到固件ACK及GET读回，不能只看发送日志。不要把J在1到1.10内的探索接受报告为已经改善。
5. 连续普通回滚超过三轮仍能继续采集；固件故障回滚或通信不确定应停止。日志包含本轮基线、候选、评价分量和最终响应。
6. 采集中、LLM等待中、候选已应用时分别停止；停止后不得出现新PREP，活动候选恢复且通信正常时应解锁。后台后不得自行恢复。
7. 实车报告请附HEX版本、Web版本、模式、电压、完整JSON，以及实际是否抖动/漂移/倾倒。机器模拟不代替实车稳定性验证。
