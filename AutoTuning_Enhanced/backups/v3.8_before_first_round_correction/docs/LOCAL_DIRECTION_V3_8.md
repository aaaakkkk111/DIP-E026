# Web v3.8：先确定方向，再让 LLM 决定幅度

本次仅增加发给 LLM 的局部对照上下文与方向优先提示。固件、5 Hz 快遥测、200 Hz 特征计算、六 PID 范围、接受/回滚、3 秒采集 / 1 秒评价、轮间等待、BLE 协议及界面布局保持 v3.7。

## 输入与方向

新增 local_direction_summary，取本次自动运行中最近最多五个可衔接到当前 PID 的同来源试验。只有确认曾应用、已有完整评价和有效 osc/lean 的接受/回滚记录进入摘要。每项列出事务 ID、时间、所有被改参数、改前改后的指标及方向；协同调整明确标注 AD 效应未被独立辨识。新自动会话不沿用旧会话的局部方向，原 recent_history 仍保留。

- 提高 AD 后 osc 恶化：若当前 osc 仍是主要问题，优先降低 AD。
- 降低 AD 后 osc、lean 均改善：继续该方向或保持观察。
- 进一步降低 AD 后指标反而变差：停止盲目下降，重新判断。
- osc 已低但仍低频摇摆：优先检查 AP 与速度环。
- 达到有证据支持的实验稳定目标：hold，保持 PID，原循环继续观察；本次不新增固定目标数值或停机条件。

首轮 AP150/AD120/VP62/VI31/TP17/TD20 的空载高 osc、倾角仍相对受控场景，以降低 AD 为主要初始假设，结合当前 lean 决定 AP/VP/VI 是否联动。这不是固定 PID 目标，也不适用于所有低 AD 大角度失败。

反向调整仍允许，提示词要求 expected_effect 引用新的实测证据（事务 ID/时间、指标前后值，或新基线/环境变化），不能只以“增加阻尼”为依据。这里是模型指导，不新增语义拒绝器、强制档位、百分比限幅或额外 LLM 调用。六参数仍允许大幅协同改变。试验改进需要实车验证，单窗口变化不证明因果或统计显著性。
