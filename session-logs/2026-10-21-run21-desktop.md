## Verdict: partial, failing one criterion

**Criteria set before the run:**

| criterion | result |
|---|---|
| Calm empty (< 10 deg/s) | pass at 15–22M |
| Calm with 2 kg | pass |
| 3 N pushes both ways | **fail when empty** |

**What passed:**
- **The first policy calm both empty and loaded.** The 21M checkpoint stands at about the PID's
  level empty (6.6–8.3 against 6.6–6.9). It is 3× calmer than run 15 empty, reverses 3–5× less,
  and is calmer than run 15 at every load. That holds at 4° of slack too (11–13 against 35–44).
- **With load it is the best so far:** 4 N pushes survived 18/18 with 2 kg, and it drives
  0–2 kg at full speed.

**What failed:**
- **Push recovery on an empty car:** 2 N 1–3/18 and 3 N 0/18, against the PID's 18/17 and
  run 15's 18/18.
- A trace of a 2 N empty push (20M) shows the policy *reducing* its drive as the car tips:
  0.43 at 50 ms, 0.15 at 100 ms (10°), 0.02 at 150 ms (21°). It falls at about 210 ms.
- Freezing `osc` and `lean` at calm values did not help (0/18). So the inputs aren't the cause;
  the policy is too soft on a light car.
- Empty push recovery appeared only late (30M: 2 N 11/18), and by then the empty wobble had
  doubled and the 4° car fell 3 times in 6.

**Recommended candidate if a car test is wanted:** 21M (`models/ckpt_run21/rl_model_20999*`), or
the 22.2M best for a 4 kg drive. Either needs the `osc`/`lean` firmware change first.

## Tooling caveat found this session

Since run 20, the simulator puts `osc` and `lean` into `obs[5:7]` for **every** policy the
test tools load. Policies trained before run 20 saw zeros there, and give wrong results
without them. Run 15 driving at 2 kg read "fell 0/3" with the new inputs, and 3/3 with zeros.

- `zero_la.py` in the session scratchpad wraps any check script to zero those slots. The run 15
  rows above use it.
- The run 15 `osc` sizing numbers in the run 20 log were taken with the new inputs: 18–25 deg/s,
  against 17.8–24.9 zeroed, so they are close but not clean.
- `sim_tools/simlib.py` still has no switch for this.
