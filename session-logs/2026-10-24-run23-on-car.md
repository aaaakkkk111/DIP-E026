## 3. Run 22 vs run 23 on the car

| | run 22 (8 s memory, trim 1.7°) | run 23 (full memory) |
|---|---|---|
| calm empty / 2 kg | 4.0–4.3 / 2.7 | 3.7–5.5 / 3.6–4.9 |
| creep | 0.1–0.5 cm/s, steady | none |
| swing around the spot | small | ±10 cm empty, ±20 cm with 2 kg |
| after a push | back in about 10 s | wanders ±10–25 cm for 30 s |
| needs the right trim | yes, and it changes with the load | no |
| heaviest load, simulator | drives 4 kg 3/3 | drives 4 kg 2/3 |

**Neither wins outright.** A full memory removes the creep and the trim, at the cost of a PI-like
overshoot after pushes.

The middle option, a leaky memory of about 30 s retrained as run 24, was discussed and **left for
now** (user, 2026-10-24). It must be retrained, not just re-flashed: the network's response is
tuned to its own memory length.
