## Verdict: fail, not exported

- Standing is no calmer than run 15.
- It loses all 3 N pushes.
- The final checkpoint can't drive with 1 kg on board.

## What it tells us

- C (10M) was calm and run 18 (30M) is not. Both trained without payload and
  annealed the same way.
- So payload was not the only cause. The remaining difference is time at full
  curriculum strength (about 5M steps for C, about 15M for run 18).
- Removing payload delays the shake but doesn't stop it, which is the same
  "calm early, shaky late" pattern as runs 14–17.
- This is inferred from two runs, not isolated.

## Next (needs the user's decision on what load the car must carry)
