# 2026-10-18 (desktop) — Run 15: shoves capped at 3 N, wobble penalty paused after shoves

Follows `2026-10-14-run14-desktop.md` (§3–4 proposed this run). Training
progress: `train_real_robot_RUN15_push3N_penaltypause_progress.csv`.

## Summary

- **Run 15 final is the best policy so far in simulation.** It survives 3 N
  in 18 of 18 trials, like run 13, and stands about 20 % calmer: 19.5–24.5
  deg/s at 2° slack, against run 13's 23.8–32.8.
- **It still misses the calm target** of about 10 deg/s; the stock PID is at
  6.6–6.9.
- By the guide's general flash rule (no wobblier than the last, all
  training-like cars hold, tracking above ~85 %, at least as many pushes
  survived), it qualifies to replace run 13. Not exported yet.

## 1. Changes from run 14 (`train_real_robot.py`)

- `PUSH_MAX_N` 4.0 → **3.0**: the stock PID survives 3 N × 0.1 s but never
  4 N, and 10–23 % of run 14's shoves were above its limit.
- **`PENALTY_PAUSE_S = 1.0`**: no wobble penalty during a shove or for 1 s
  after it (`_calm_pause` in `PWMCommandWrapper`), so recovering hard isn't
  charged.
- Everything else as run 14: from scratch, 30M steps, penalty 1.5. Eval and
  test cars stay push-free.
- Self-check before training, run with run 13 balancing: 13 shoves, all at or
  under 3 N (largest 2.95 N); the pause lasted 213–227 ticks from the start
  of each shove. About 35 % of training ticks are penalty-free.

## 4. Reading

- **The 3 N cap and the pause helped:** run 15 final has run 13's push
  tolerance at run 14's calm, and is calmer than run 13 at both 2° and 3°.
- **The trade-off is still there.** In both runs 14 and 15 the wobble rose
  from about 10 to about 20 deg/s exactly while push recovery was being
  learned. A reward change won't buy PID-level calm on its own; the policy
  keeps finding that a twitchier controller recovers better.
- **On the car**, scaled from run 13 (sim 24–33, car 26–36), expect run 15
  final at about 21–27 deg/s standing, with run 13's push recovery.
